# Product Search Rules

Product search should return wearable fashion products only: clothing, footwear, ethnic wear, watches, bags, eyewear, jewelry, and accessories.

Avoid beauty, makeup, skincare, home goods, electronics, groceries, medicine, books, toys, and unrelated products.

Rank products by category match, gender preference, budget fit, occasion/style words, image availability, try-on compatibility, rating, and source quality.

For occasion requests, every result must be genuinely suitable for that occasion rather than merely belonging to a broad clothing category. Build a useful capsule across relevant product groups instead of repeating one garment type.

For a general beach or resort request, prioritize swimwear such as swimsuits, bikinis, monokinis, and tankinis; beach cover-ups such as kaftans and sarongs; breathable linen or crochet tops and shorts; sandals; sunglasses; and sun hats. A generic dress is not a beach result unless its title or description contains clear beach, resort, vacation, summer, linen, crochet, or cover-up evidence. Regular underwear and lingerie are not swimwear and should appear only when the user explicitly asks for innerwear.

If live marketplace cards are unavailable, AI Studio may use Lookmefy catalog fallback products, but it should label them clearly as catalog results.
