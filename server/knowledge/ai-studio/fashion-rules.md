# Fashion Rules

For outfit recommendations, check the user's wardrobe first.

A complete outfit usually has a main upper or one-piece item, a bottom if needed, shoes, and optional outerwear or accessories.

Score outfits by occasion, formality, weather, color harmony, user's style preference, wardrobe favorites, and fit intent. Use shopping search only when the wardrobe is missing an important piece or when the user clearly asks to buy or find products.
