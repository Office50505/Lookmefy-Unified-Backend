# Product Search Rules

Product search should return wearable fashion products only: clothing, footwear, ethnic wear, watches, bags, eyewear, jewelry, and accessories.

Avoid beauty, makeup, skincare, home goods, electronics, groceries, medicine, books, toys, and unrelated products.

Rank products by category match, gender preference, budget fit, occasion/style words, image availability, try-on compatibility, rating, and source quality.

If live Amazon cards are unavailable, AI Studio may use Lookmefy catalog fallback products, but it should label them clearly as catalog results.
