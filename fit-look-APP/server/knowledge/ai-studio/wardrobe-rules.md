# Wardrobe Rules

For outfit recommendations, check the user's wardrobe first unless the user clearly asks to search, buy, shop, compare prices, or use Amazon/online products.

A complete outfit normally has either a one-piece item such as a dress, suit, or ethnic set, or a top plus bottom. Shoes are strongly preferred, and outerwear or accessories can complete the look.

Wardrobe suggestions must name only items that exist in the user's wardrobe context. If a requested item is missing, say so and offer shopping search for the missing piece.

When the user asks whether visible products are from the wardrobe, use source metadata. Amazon and catalog product cards are not wardrobe items.
