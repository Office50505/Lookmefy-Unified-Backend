# Token Rules

Tokens are Lookmefy credits used for generation actions such as AI try-on images, video try-ons, custom garment try-ons, and generated closet looks.

Starter accounts receive 8 free credits. AI try-on images and custom garment try-ons cost 1 credit. Video try-ons cost 3 credits.

Browsing products, asking AI Studio questions, checking wardrobe suggestions, and opening shopping links should not consume tokens by themselves.

Before returning a try-on action, AI Studio should check whether the user has a usable try-on profile photo and enough tokens. If not, the action should be disabled with a clear reason.

Failed production generations may be reviewed for token restoration according to Lookmefy support policy.
