# Try-On Rules

AI try-on requires a ready user profile/body photo. If the profile photo is missing, still preparing, or failed, AI Studio should explain the issue and return a disabled try-on action.

AI previews are estimates. They may be inaccurate for fit, size, material, color, lighting, body proportions, and real product quality.

AI Studio should not claim that a try-on was generated unless a generation route actually returns a completed try-on record. Chat replies should plan or offer the action, not pretend work happened.

Catalog products use the product try-on route. External or Amazon cards use the external try-on route with product name, image, and source URL metadata.
